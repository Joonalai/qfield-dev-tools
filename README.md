# qfield-dev-tools

Tools for developing and testing [QField](https://github.com/opengisch/QField) and its plugins.

## Components

- [qfield-fetch](components/qfield-fetch/README.md): downloads QField AppImages and QField and QFieldCloud sources into one cache.
  [![PyPI](https://img.shields.io/pypi/v/qfield-fetch)](https://pypi.org/project/qfield-fetch)
- [pytest-qfield](components/pytest-qfield/README.md): a pytest plugin for testing QField QML plugins.
  [![PyPI](https://img.shields.io/pypi/v/pytest-qfield)](https://pypi.org/project/pytest-qfield)
- [qfield-driver](components/qfield-driver/README.md): drives a real QField app from Python, with a local QFieldCloud.
  [![PyPI](https://img.shields.io/pypi/v/qfield-driver)](https://pypi.org/project/qfield-driver)
- [pytest-qfield-e2e](components/pytest-qfield-e2e/README.md): pytest fixtures for QField plugin and end-to-end tests against a real QField app.
  [![PyPI](https://img.shields.io/pypi/v/pytest-qfield-e2e)](https://pypi.org/project/pytest-qfield-e2e)
